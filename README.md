# 🎉 Evencers

Evencers is a modern event management platform that helps users discover, create, manage, and participate in events seamlessly. The platform provides an intuitive user experience for attendees, organizers, vendors, and service providers.

## 🚀 Features

* User Authentication & Authorization
* Create, Edit, and Manage Events
* Event Registration & Ticket Booking
* Vendor & Service Provider Management
* Responsive UI for Mobile and Desktop
* Real-time Event Updates
* Secure API Integration
* Dashboard for Event Organizers
* Search & Filter Events
* User Profile Management

## 🛠️ Tech Stack

### Frontend

* React.js
* Next.js
* JavaScript (ES6+)
* Tailwind CSS / CSS3
* Axios

### Backend

* Node.js
* Express.js

### Database

* MongoDB
* Mongoose

### Other Tools

* Git & GitHub
* REST APIs
* JWT Authentication

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/evencers.git
```

### Navigate to Project

```bash
cd evencers
```

### Install Dependencies

```bash
npm install
```

### Setup Environment Variables

Create a `.env` file and add:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Run Development Server

```bash
npm run dev
```
